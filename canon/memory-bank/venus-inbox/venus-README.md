# INBOX — задания Venus → Mac

Каноническая папка сброса. Агент Cursor на **Venus** пишет сюда новые задачи.
Агент на **Mac** забирает их сам (`node scripts/venus-inbox-pull.mjs`) — человека просить «прочитай инструкцию с Venus» не нужно.

## Как положить задачу

1. Создай файл: `YYYY-MM-DD-HHMM-topic.md`  
   Пример: `2026-08-15-2145-fix-split.md`
2. Пиши по-русски: цель, что сделать, пути, ограничения.
3. Один файл — одна задача. Не перезаписывай чужие файлы.

## Не класть сюда (если можно)

- Пароли, токены MCP, файлы `.env`, ключи API.
- Если токен всё же нужен — файл можно оставить; Mac-агент **не должен** печатать его в чат.
