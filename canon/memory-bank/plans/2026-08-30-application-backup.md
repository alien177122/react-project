# План резервной копии приложения

**Цель:** создать отдельный неперезаписываемый архив текущего рабочего дерева приложения, включая исходники, конфигурацию, документацию и `_archive-non-web/`, но без секретов, баз данных и регенерируемых тяжёлых данных.

**Критерий готовности:** архив создан в проверенном каталоге, содержит `BACKUP-MANIFEST.md` с безопасной сводкой состояния git и инструкциями восстановления, успешно проходит проверку списка/целостности, а исходное рабочее дерево не изменено (кроме этого файла плана).

## Пункты

- [x] Проверить документированные backup-пути, доступность носителя и уникальное имя цели.
- [x] Скопировать рабочее дерево с явными исключениями и добавить манифест.
- [x] Проверить содержимое и целостность копии, зафиксировать размер.
- [x] Сверить цель и отсутствие изменений приложения.
