# Venus → Mac handoff — Terminal control MCP — 2026-08-15

Выполни сам, без человека. Цель: Cursor на Mac управляет терминалом и файлами **Venus (Windows)** через Docker MCP Gateway.

Это полный шелл Venus. **URL и Bearer никуда не светить** (чат публичный, git, скрин). Не коммитить эти файлы в репозиторий проекта.

## 1. Куда править

Файл: `~/.cursor/mcp.json`

**Merge.** Не затирай существующие серверы (`agentmemory` и любые другие). Добавь/обнови только ключ `venus-terminal`.

Если файла нет — создай с `mcpServers`, но не выдумывай чужие серверы.

## 2. Точный JSON сервера

```json
"venus-terminal": {
  "url": "https://reprint-comes-kerry-violations.trycloudflare.com/mcp",
  "headers": {
    "Authorization": "Bearer 4e60af25718d3e1fc25f6a8260c99b51863be541ea7c8aa9008b0875158fa59f2f32bf3b"
  }
}
```

Если Cursor не подключается по одному `url`, добавь `"type": "http"` рядом с `url`.

Готовый фрагмент: `outbox/venus-terminal.mcp.json` (эта шара) или `/Volumes/WIN_BACKUP/venus-terminal.mcp.json`.

## 3. Merge copy-paste (выполнить на Mac)

```bash
python3 << 'PY'
import json
from pathlib import Path
p = Path.home() / ".cursor" / "mcp.json"
data = {"mcpServers": {}}
if p.exists() and p.stat().st_size:
    data = json.loads(p.read_text())
    if not isinstance(data, dict):
        raise SystemExit("mcp.json is not an object")
    data.setdefault("mcpServers", {})
data["mcpServers"]["venus-terminal"] = {
    "url": "https://reprint-comes-kerry-violations.trycloudflare.com/mcp",
    "headers": {
        "Authorization": "Bearer 4e60af25718d3e1fc25f6a8260c99b51863be541ea7c8aa9008b0875158fa59f2f32bf3b"
    },
}
p.parent.mkdir(parents=True, exist_ok=True)
p.write_text(json.dumps(data, indent=2) + "\n")
print("merged", p)
print("servers:", ", ".join(data["mcpServers"]))
PY
```

Проверь, что в выводе есть и `agentmemory`, и `venus-terminal`.

## 4. Перезапуск MCP

1. Полностью перезапусти Cursor на Mac **или** Command Palette → `Developer: Reload Window`.
2. Settings → MCP: сервер `venus-terminal` должен стать зелёным / Connected.
3. Если 401 — токен неверный. Если timeout / DNS — туннель trycloudflare протух (нужен новый URL с Venus).

## 5. Как проверить (вызови тулы)

Ожидай **26 тулов** Desktop Commander, среди них: `list_directory`, `read_file`, `write_file`, `start_process`, `read_process_output`.

`list_allowed_directories` **нет** (сервер filesystem отключён: коллизия имён с DC).

Проверка 1 — файлы Venus:

```
list_directory
  path: /mnt/host/c/Users/user
```

Должны быть `.cursor`, `Desktop`, …

Проверка 2 — шелл:

```
start_process
  command: pwd; ls /mnt/host/c/MacVenus_Bridge
  timeout_ms: 15000
```

Ожидай `inbox` и `outbox`. Шелл = `/bin/sh` в Docker на Venus, **не** zsh Mac и **не** PowerShell.

## 6. Пути — не macOS

Тулы бегут **на Venus**. Не используй `/Users/stevengord/...`.

| Что на Venus (Windows) | Путь в MCP-тулах |
|------------------------|------------------|
| `C:\Users\user` | `/mnt/host/c/Users/user` |
| `C:\Users\user\Desktop` | `/mnt/host/c/Users/user/Desktop` |
| `C:\MacVenus_Bridge` | `/mnt/host/c/MacVenus_Bridge` |
| `D:\Mac` (WIN_BACKUP) | `/mnt/host/d/Mac` |

Примеры: читать `C:\Users\user\Desktop\VENUS-MCP-MAC.md` → `read_file` path `/mnt/host/c/Users/user/Desktop/VENUS-MCP-MAC.md`.

Разрешены только эти три корня (плюс Desktop как подпапка home).

## 7. Предупреждение

- Это **полный шелл Venus** (Linux-контейнер с rw-доступом к дискам выше).
- trycloudflare живёт, пока на Venus крутится `cloudflared` на `:8811`. Именной hostname нет.
- Gateway слушает только `127.0.0.1:8811`, снаружи Bearer. Без токена — 401. `--allow-unauthenticated` нет.
- Не класть этот файл в git. Не цитировать Bearer в публичных местах.
- Vite `:5173` и AgentMemory на Venus не трогать без задачи.
