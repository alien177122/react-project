# Диагностика ERR_CONNECTION_REFUSED для Vite

**Цель:** восстановить локальный dev-сервер проекта на `localhost:5173`, если слушатель отсутствует, и подтвердить доступность корневого URL и split-маршрута без изменения продуктового кода.

**Критерий готовности:** `lsof` показывает слушатель на `5173`, оба URL возвращают HTTP 200, а причина отказа и состояние stale terminal metadata зафиксированы в отчёте.

## План

- Проверить listener, HTTP и metadata существующего dev-терминала.
- Запустить свежий `npm run dev`, если listener отсутствует.
- Повторно проверить оба URL и открыть split preview во встроенном браузере.
