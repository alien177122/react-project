# Goal-first plan (канон агента)

**Цель этого документа:** агент не начинает работу, пока нет MD-плана с явной целью.

## Цикл (обязателен)

1. **Задание.** Прочитать запрос. Сформулировать цель одним абзацем.
2. **Если цель неясна** — один уточняющий вопрос. Не писать код и не плодить файлы «на всякий случай».
3. **План-файл.** Создать или обновить MD в `memory-bank/plans/` (не в корне репо). В шапке обязательно поле **Цель**. Пункты короткие, по делу, с критерием готовности.
4. **Выполнение.** Идти по пунктам плана. Не подменять цель соседней идеей.
5. **Проверка.** Когда пункты закрыты: ошибки, излишки, слабые решения; **достигнута ли цель и с каким качеством**.
6. **Если цель не закрыта** — новый план в том же каталоге, от трудностей предыдущего круга. Пока цель не достигнута настолько, насколько это возможно.
7. **Стоп.** Улучшать уже нечего, качество максимальное для этой цели — сказать пользователю и остановиться.

## Теория: секциями

Раскладка / переработка лекции: **одна глава = один план → правка → взгляд в браузере → стоп**. Не чинить 01–10 одним CSS-проходом. Следующая глава только после проверки текущей.

## Шаблон шапки плана

```md
# План: <короткое имя>

## Цель

<один абзац: что должно быть правдой, когда работа закончена>

## Критерий готовности

- …

## Пункты

1. …
```

## Не делать

- План только в чате, без файла.
- Начинать с кода, «план потом».
- Считать задачу закрытой, потому что файлы изменены, если цель не проверена.
- Смешивать две цели в одном плане (сначала закрыть одну).
