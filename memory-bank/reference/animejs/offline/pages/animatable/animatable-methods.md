## 
          
            Animatable methods                                              
        

          
        Methods available on the `Animatable` instance returned by a `createAnimatable()` function.

```js
const animatable = createAnimatable(target, parameters);
           ┌─────────────────────┐
animatable.│x(100)               │
animatable.│y(50, 500, 'out(2)') ├─ Methods
animatable.│revert()             │
           └─────────────────────┘
```
