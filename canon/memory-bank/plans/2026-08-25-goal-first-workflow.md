# План: цикл «цель → файл плана → проверка»

**Дата:** 2026-08-25  
**Статус:** выполнено, цель сверена

## Цель

Следующий агент (и этот же) **не начинает работу с кода**. Он пишет MD-план с явной целью, идёт по пунктам, в конце сам проверяет: цель достигнута или нужен новый план. Это правило живёт в **двух канонах памяти** (agentmemory + `memory-bank/`) и в **правиле Cursor**, иначе на следующем чате оно пропадёт.

Не цель этого файла: статья про кломифен. Она — отдельная задача после этого цикла.

## Почему так

Словесный «опиши план 1-2-3» в чате не держится. Нужен файл, чтобы план можно было открыть, свериться и не импровизировать.

## Критерий готовности

1. В `memory-bank/plans/` лежит этот файл с целью.
2. В `memory-bank/` есть постоянный канон алгоритма (не только сессионный снимок).
3. `memory_save` в agentmemory (slug `react-training-journal-split`) — тип `workflow` + `preference`.
4. Always-on правило Cursor ссылается на тот же алгоритм.
5. `activeContext.md` указывает на канон.
6. Самопроверка: без этого правила агент снова начнёт с кода — значит, пункт 4 обязателен.

## Пункты

1. Зафиксировать алгоритм в `memory-bank/constitution/goal-first-plan.md`.
2. Вписать его в `systemPatterns.md` и `activeContext.md`.
3. Усилить `.cursor/rules/agent-autonomy.mdc`: сначала файл плана, поле **Цель**, иначе вопрос.
4. Новое always-on правило `.cursor/rules/goal-first-plan.mdc`.
5. `memory_save` (workflow + preference), concepts: `goal-first-plan`, `plan-file`, `goal-check`.
6. Самопроверка по чеклисту выше. Если дыра — новый план, не «вроде готово».

## Самопроверка (цель)

| Критерий                   | Статус                                                      |
| -------------------------- | ----------------------------------------------------------- |
| План-файл с целью          | да, этот файл                                               |
| Канон в memory-bank        | `constitution/goal-first-plan.md`                           |
| agentmemory                | preference + workflow + lesson                              |
| Always-on правило          | `.cursor/rules/goal-first-plan.mdc` + autonomy project/user |
| activeContext              | да                                                          |
| Статья кломифен не смешана | да, вынесена                                                |

Качество: алгоритм записан в оба слоя памяти и в правило, без которого следующий чат его не обязан соблюдать. Улучшать здесь уже нечего для этой цели.
