## 2025-04-16 - Prevent Static Data Recomputation in Interactive Components
**Learning:** In highly interactive components with rapid state changes (e.g. `VolumeDonut` managing `hover` state during mouse movements), complex data derivations based on static constants (like mapping muscle volume contributions and geometry for SVG charts) can become a significant CPU drain. Since React triggers a full re-render on each interaction, having inline static derivation causes heavy recomputation inside the hot path.
**Action:** Always identify derived data that depends entirely on static constants and extract it completely out of the render loop (either using a module-level initialization or `useMemo` with an empty dependency array) to prevent unnecessary performance hits during high-frequency component updates.
