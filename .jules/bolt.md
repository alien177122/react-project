## 2024-05-06 - O(1) Data Structures in React
**Learning:** Found widespread O(N*M) existence and lookup checks in `App.tsx` (e.g., using `userData.exercises.some` inside `.filter`, or `segs.find` during frequent hover updates). Replacing these with `Set` and `Map` initialized via `useMemo` significantly reduces CPU time during render loops. However, manual `useMemo` optimizations must be cautious with dependency lists, as using mutating arrays or improper dependencies can break the React Compiler's caching guarantees. Also, the environment requires vigilance with `yarn` commands to prevent inadvertent locking downgrades, and temporary files must be aggressively cleaned before review.
**Action:** When finding `.some`, `.find`, or `.filter` in nested mappings, convert the inner array to a `Set` or `Map` using `useMemo`. Ensure the dependency list aligns with the compiler's inferred constraints, and verify fallback conditions to prevent regressions. Always double check lock files and untracked files before committing.
