## 2026-07-02 - [Memoizing Static Donut Chart Computations]
**Learning:** In a large React application where complex chart data (like multiple nested map/filter/reduce iterations) is generated entirely from static module-level constants (e.g. `EXERCISES`, `MUSCLE_ORDER`, `CAT_ORDER`), any local state change (like a hover interaction `setHov`) will trigger a full re-computation of these derivations if they are left in the main render body. The O(C*M) calculation happens on every mouse move.
**Action:** When data origins are purely static (no state/props dependencies), use `useMemo(() => { ... }, [])` to calculate the derivations once per component mount instead of on every render. Ensure the dependency array is empty since the constants are outside the React tree, safely achieving O(1) retrieval for subsequent renders.
