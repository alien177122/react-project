## 2024-05-24 - O(N x M) React render bottlenecks with find/some
**Learning:** In React components that render lists or arrays of elements (e.g. `App.tsx` computing `missingExercises` or mapping over `WHEEL_ORDER`), performing a linear search (`.find()`, `.some()`) on another array (like `userData.exercises`) inside the loop creates an $O(N \times M)$ bottleneck on every render.
**Action:** Replace these linear searches with a `useMemo` that indexes the array into a `Set` (for existence checks) or `Map` (for data retrieval). This reduces the complexity to $O(N)$ and avoids redundant iterations during renders. Always remember to use the object or array as the dependency array instead of `JSON.stringify` or properties that could cause manual memoization preservation to fail.
