## 2024-04-17 - Optimize high-frequency hover updates in React
**Learning:** When a component (like `VolumeDonut`) performs nested iterations to process domain configurations (e.g. iterating over categories, muscles, and calculating arc properties) and has high-frequency state updates like mouse hovers, doing the heavy computation directly in the render function causes jank. However, moving those computations to a module-level IIFE breaks reactivity if the underlying data later depends on props or user configurations.
**Action:** Use `useMemo` with an empty dependency array (or specific dependencies if they exist) to calculate expensive derivations inside the component. This gives the performance benefits of computing once, while ensuring the code remains ready for future reactivity needs, preventing unexpected bugs down the road.
